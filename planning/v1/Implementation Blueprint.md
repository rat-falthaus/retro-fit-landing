# **Project: "SmartHarvest" Retro-fit Landing Page**

## **1\. Technical Stack**

* **Framework:** Vue 3 (SFC)  
* **Language:** TypeScript  
* **Build Tool:** Vite  
* **Styling:** Tailwind CSS \+ PrimeVue (for sophisticated UI components)  
* **Icons:** Lucide-Vue-Next or Phosphor Icons (for a technical/industrial look)  
* **Animations:** AOS (Animate on Scroll) or GSAP for smooth section transitions.

## **2\. Page Architecture (The "One-Pager" Flow)**

1. **Hero Section:** The "Hook." Large-scale imagery of heavy machinery. Catchy slogan. High-contrast CTA.  
2. **The "Postcard Bridge":** A small section referencing the funny hook from the physical mailer to ensure continuity.  
3. **The Problem/Solution (Retro-fit):** "Your machine isn't old; it's just waiting for an upgrade." Side-by-side comparison (The Old Way vs. The Smart Way).  
4. **Examples & Tech Specs:** Interactive cards showing specific machines (Hay presses, Tractors, Harvesters) with retrofitted sensors/GPS/AI.  
5. **The Value Proposition:** Massive banner for the **"€2,000 Free Retro-fit Check."**  
6. **The Transition (CTA):** Lead capture that directs users to the main website registration.  
7. **Footer:** Technical standards, social proof, and domain info.

## **3\. Directory Structure**

## **4\. Branding & Visual Language**

* **Primary Color:** \#2D5A27 (Deep Forest Green \- Trust/Agriculture)  
* **Accent Color:** \#F59E0B (Industrial Amber \- Alert/Action/Machinery)  
* **Secondary Color:** \#1E293B (Slate \- Modern Tech/Steel)  
* **Typography:** 'Inter' for body, 'Bebas Neue' or 'Roboto Condensed' for heavy industrial headers.
